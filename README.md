# YT-Downloader

![Build](https://img.shields.io/github/actions/workflow/status/GratifluxTools/YT-Downloader/build.yml)
![Release](https://img.shields.io/github/v/release/GratifluxTools/YT-Downloader)
![License](https://img.shields.io/github/license/GratifluxTools/YT-Downloader/LICENSE)

A simple and powerful GUI downloader for YouTube and supported sites, powered by **yt-dlp**, **ffmpeg**, and **PySide6**.
You can download videos and audio, embed thumbnails and metadata, manage multiple downloads, and update yt-dlp directly from the app.

yt-dlp・ffmpeg・PySide6 を使用した、シンプルで高機能な GUI ダウンローダーです。
動画・音声のダウンロード、サムネイル・メタデータ埋め込み、複数同時ダウンロード管理、アプリ内からの yt-dlp 更新に対応しています。

---

## ✨ Features / 機能

**English**

* GUI application (Windows)
* Download video or audio (mp4 / mp3 / mkv / wav / webm / m4a)
* Embed thumbnail into media files
* Embed metadata
* Import `cookies.txt` (for member-only / age-restricted videos)
* Up to **3 concurrent downloads**
* Real-time progress and logs
* Open output folder quickly
* Built-in yt-dlp updater
* English / Japanese UI
* GitHub release auto-check

**日本語**

* Windows向けGUIアプリ
* 動画・音声ダウンロード対応（mp4 / mp3 / mkv / wav / webm / m4a）
* サムネイル埋め込み
* メタデータ埋め込み
* `cookies.txt` の読み込み対応（会員限定・年齢制限動画など）
* **最大3件まで同時ダウンロード**
* リアルタイム進捗・ログ表示
* 保存フォルダをワンクリックで開く
* yt-dlp の自動更新機能
* 英語 / 日本語 UI 切り替え
* GitHub の最新リリース自動チェック

## 🚀 How to Use / 使い方

**English**

1. Launch the application.
2. Paste a YouTube (or supported site) URL.
3. Select output folder and format.
4. (Optional) Enable thumbnail / metadata embedding.
5. Click **Add URL**.
6. Download starts automatically.

Right-click a task to delete it.
Maximum 3 downloads run in parallel.

**日本語**

1. アプリを起動します。
2. YouTube（または対応サイト）のURLを入力します。
3. 保存先フォルダと形式を選択します。
4. （必要に応じて）サムネ・メタデータ埋め込みを有効にします。
5. **URL 追加** を押します。
6. 自動でダウンロードが開始されます。

タスクは右クリックで削除できます。
同時実行は最大3件までです。

## 🍪 Cookies Support / cookies 対応

**English**
If you need to download age-restricted or login-required videos:

1. Export cookies as `cookies.txt` from your browser.
2. Click **Import cookies.txt** in the app.
3. Select the file.

**日本語**
年齢制限・ログイン必須動画をダウンロードする場合：

1. ブラウザから cookies を `cookies.txt` としてエクスポートします。
2. アプリの **cookies.txt をインポート** をクリックします。
3. ファイルを選択します。
